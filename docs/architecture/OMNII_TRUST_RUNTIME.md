# OMNII TRUST RUNTIME

Trust is contextual evidence about whether a subject, object, source, capability, or interaction should be relied upon for a stated purpose.

## Inputs
Identity, provenance, attestations, history, policy, context, observed behavior, security state, and recency.

## Model
Trust is not binary and is never a substitute for authority. Trust may change, expire, be scoped to purpose, and be revoked.

## Runtime
`assess → qualify → permit/restrict → observe → reassess`

Compromised or anomalous subjects may be quarantined without destroying their historical evidence.
