# OMNII UNIVERSAL WORKFLOW CONTRACT

## Purpose
Define a universal executable structure for turning intent into coordinated work.

## Workflow Contract
A workflow contains intent, inputs, steps, dependencies, actors/agents, capabilities, resources, conditions, transitions, outputs, and audit records.

## Execution Model
Trigger → Validate → Plan → Authorize → Execute → Observe → Branch/Retry/Escalate → Complete/Fail → Record.

## Invariants
Workflow state is explicit. Steps cannot exceed authority. Side effects are attributable. Failures and retries remain observable.

## Composition
Workflows compose executions, capabilities, resources, relationships, events, and integrations.

## ABBA
ABBA may design, schedule, route, adapt, and monitor workflows within delegated authority.
