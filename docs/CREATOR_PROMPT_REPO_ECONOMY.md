# OMNII Creator, Prompt & Repository Economy

**Status:** Draft Canonical / Extension to Global Value, Finance & Payment Network
**Scope:** Creator economy, prompt economy, repository/software economy and their value chains

## Purpose

Creative work, prompts, source code, repositories, documentation, models, datasets and digital production are first-class economic value. OMNII must be able to identify, govern, license, exchange, finance, monetize, preserve, transform and recover these forms of value without reducing them to generic files or content.

## 4. Prompt Economy

Prompts are treated as potentially valuable intellectual/digital assets where original, useful, transferable or commercially licensed. Examples include:

- System prompts
- Workflow prompts
- Task prompts
- Agent instructions
- Prompt chains
- Prompt templates
- Role prompts
- Evaluation prompts
- Domain-specific prompts
- Image/video/audio prompts
- Coding prompts
- Research prompts
- Structured prompt programs
- Prompt libraries
- Prompt packs
- Prompt workflows
- Prompt-to-tool specifications
- Reusable agent procedures

Prompt value can arise from:

`originality + performance + reproducibility + domain expertise + evaluation evidence + workflow integration + scarcity + license rights + demand`

Prompt lifecycle:

```text
IDEA
 -> PROMPT AUTHORING
 -> TESTING
 -> EVALUATION
 -> VERSIONING
 -> PROVENANCE
 -> LICENSING
 -> SALE / SUBSCRIPTION / ACCESS
 -> USAGE
 -> PERFORMANCE FEEDBACK
 -> IMPROVEMENT
 -> DERIVATIVE / FORK
 -> NEW VALUE
```

A prompt is not automatically protected by copyright merely because it is a prompt; legal rights depend on jurisdiction and facts. OMNII therefore records authorship, provenance, contracts and licenses without making unsupported legal-title assumptions.

## 11. Dependencies as Value Relationships

A repository's dependencies create a value graph:

```text
PROJECT
 -> DEPENDS ON
 -> LIBRARY
 -> DEPENDS ON
 -> ANOTHER LIBRARY
```

OMNII can use this to identify:

- license obligations
- security exposure
- abandoned dependencies
- maintainer risk
- supply-chain risk
- concentration risk
- upgrade obligations
- support dependencies
- replacement opportunities
- funding needs

A dependency is not merely technical metadata; it can create legal, operational, financial and continuity obligations.
