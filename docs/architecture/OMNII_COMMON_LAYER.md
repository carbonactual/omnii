# OMNII Common Layer

**Status: CANONICAL — reusable ecosystem fabric — 2026-09-05**

The OMNII Common Layer is the shared semantic fabric used by products, institutions, territories, agents and ecosystems. It is **not** a new constitutional kernel, graph, authority system or ledger.

## Core interaction

`ENTITY/IDENTITY + RELATIONSHIP + INTENT + CAPABILITY + CONTEXT + AVAILABILITY → DISCOVERY → MATCH → AUTHORITY/AUTHORIZATION → ACTION/EXECUTION → OUTCOME/EVIDENCE → SETTLEMENT/LEDGER → PULSE/LEARNING`

## Common denominators

Identity; Relationship; Intent; Capability; Discovery; Matching; Context; Availability; Lifecycle; Trust; Authority; Authorization; Resource; Property; Rights; Value; Exchange; Market; Offer; Order; Transaction; I/O; Settlement; Management; Communication; Document/Evidence; Workflow; Location/Time; Compliance/Risk; Analytics/Learning; Interoperability.

## Semantic rules

**Identity** answers who/what. **Relationship** describes how entities connect. **Intent** describes desired outcomes. **Capability** describes what a participant or service can do. **Discovery** reveals eligible/visible possibilities. **Matching** proposes a relationship between intent and capability.

A match is not authority. A capability is not permission. Authentication is not trust. Evidence is not authority. Tokenization is not proof of ownership or legal power.

**Authority** establishes who may act, over what, under which constraints and during what validity period. **Authorization** is the governed decision to permit a concrete consequential action within that authority. **SEAL** remains the human/legal approval boundary where required.

**Context** binds location, time, jurisdiction, identity, relationship, availability, history and circumstances. **Lifecycle** describes governed state progression. Product-specific lifecycles remain configurable domain contracts over the common lifecycle vocabulary.

**Resource/property/rights** generalize things, custody, ownership, usage and legal/economic claims without making every resource property.

**Value/exchange/market/offer/order/transaction/settlement** provide universal economic composition. Financial instruments are domain specializations, not separate constitutional kernels.

**I/O** governs movement and exchange across people, goods, value, information, services, rights and obligations. **Management** composes planning, assignment, coordination, monitoring, approval, execution, escalation and measurement.

**Communication** is channel-neutral; email, SMS, WhatsApp, APIs, agent protocols and future transports are adapters. **Documents/evidence** attach provenance and support to entities, events, decisions and transactions.

**Workflow** is shared orchestration; institutions/products configure it rather than rebuild it. **Location/Time** are universal dimensions of context. **Compliance/Risk** evaluates rules, eligibility, restrictions and evidence. **Analytics/Learning/Pulse** closes the feedback loop. **Interoperability** provides provider-neutral API, connector, protocol, webhook and import/export boundaries.

## Canonical persistence

The Common Primitive Registry is `public.omnii_common_primitives`.

Intent-to-capability matching is `public.omnii_intent_capability_matches`.

Existing OMNII canonical tables remain authoritative for their respective semantics: objects, relationships, authorities, operating contexts, workflows/processes/tasks, events, evidence, economic records, ledgers and registries.

## Product composition

BUNK, I/O, Value System, Management, InstituteGPT, NOUN BOT, RITES and future products consume this fabric. They may add domain-specific schemas, policies, workflows and presentation but must not create alternate universal semantics.

## Agentic interoperability

External standards such as REST APIs, MCP, A2A and current commerce protocols are integration bindings. OMNII keeps capability discovery and interoperability separate from authority and settlement so a provider or protocol can change without changing constitutional semantics.

## Boundary

`ABBA/AGENT = intelligence + orchestration`

`COMMON LAYER = reusable semantics + composition`

`AUTHORITY/SEAL = permission + human/legal control`

`RUNTIME = deterministic execution + state transition + event + audit`

`LEDGER/PULSE = resulting record + ecosystem feedback`

No component may cross these boundaries merely because it is technically capable of doing so.
