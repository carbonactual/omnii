# OMNII SECRETS MODEL

Secrets include credentials, private keys, tokens, signing material, recovery material, and other sensitive authentication or authorization data.

## Controls
Centralized secret lifecycle, encryption at rest and in transit, scoped access, rotation, expiration, revocation, non-disclosure in telemetry, and emergency recovery.

Secrets must never be treated as ordinary configuration or exposed through logs, events, audit records, or agent context without explicit policy.
