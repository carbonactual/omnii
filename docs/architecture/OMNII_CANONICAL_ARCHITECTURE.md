# OMNII Constitutional Architecture

**Status: CANONICAL — strengthened Phase 1–40 architecture**

OMNII is the constitutional operating-environment architecture for the Carbon Actual ecosystem. It provides universal semantics and governed composition for human–AI, institutional, territorial, economic, cultural and civilization-scale systems.

## 1. Constitutional Frame

OMNII operates as a governed feedback architecture:

`BEING → INTELLIGENCE → IDENTITY/AUTHORITY → FOUNDATION → DOMAINS → RUNTIME → FLOOR → EVIDENCE/PULSE → BECOMING → BEING`

This loop supports learning and evolution without allowing runtime capability or AI to self-authorize constitutional change.

## 2. Foundational Kernels

The canonical sequence remains:

`BEING → IDENTITY → KNOWLEDGE → MOTION → VALUE → TRUST → RELATIONSHIP → INTENT → EXECUTION → CAPABILITY → RESOURCE → COMPOSITION → CONTINUITY → INTEGRATION`

Governance, security, economics, ABBA/orchestration, audit, observability and resilience remain cross-cutting controls rather than additional kernels.

## 3. Intelligence and Authority

ABBA is the master interpretive/orchestration intelligence. It may perceive, reason, plan, curate, route, compose, delegate, monitor, learn and escalate within delegated authority. ABBA is not sovereign authority.

`Interpretation ≠ Authority`

Every consequential action remains subject to identity, authority, policy, capability, resource, consent where required, execution and audit boundaries.

## 4. Identity, Consent and Authority

Every governed object uses the canonical envelope:

`identity + type + version + lifecycle + provenance + authority context + attributes + relationships + dependencies + capabilities + resources + timestamps + extensions`

`#` represents the higher-order identity/provenance geometry expressed through that envelope and universal graph.

`SEAL` represents required human/legally valid approval and consent boundaries. Authentication, authorization, trust and consent remain distinct.

## 5. Canonical Foundation

The foundation family remains:

- **TERMINAL** — controlled intake and routing boundary;
- **ROOT** — origin, lineage and durable continuity context;
- **INDEX** — canonical indexing/collective-information function;
- **ATLAS** — governed public/discoverable representation;
- **VAULT** — protected custody and sensitive-record boundary;
- **ACTUAL** — curated operational-reality/actionable composition layer;
- **BECOMING** — durable evolution and continuity record.

These are functions within the canonical architecture, not competing systems of record where another canonical authority exists.

## 6. Universal Graph

`Object --[typed Relationship]--> Object`

Consequential relationships carry semantics including authority, provenance, lifecycle/status and temporal validity where applicable. Dependency remains semantically distinct from ordinary relationship.

No product, ecosystem or phase package may establish an alternate universal graph.

## 7. Domains

The existing domain/pillar model remains extensible. Finance, religion, creed, education, governance, trade, community and infrastructure remain useful lenses. Domain classification may expand without changing constitutional kernels.

## 8. Event, State, Pulse and Evidence

An event records an occurrence/observation and is distinct from command, action, execution, workflow and state.

State represents a modeled condition. State transitions are governed changes and should produce observable events.

Pulse is ecosystem feedback derived from consequential activity, movement, communication, relationships, transactions, proofs, events, telemetry and state transitions where defined by domain contract.

Evidence preserves support and provenance for claims, observations and decisions. Evidence is not authority.

## 9. Registries

Registries index canonical objects, relationships, dependencies, capabilities, resources, products, services and agents for defined semantic domains.

A registry MUST preserve identity, provenance, authority, lifecycle, ownership/custody, relationships and auditability and MUST NOT create competing definitions for the same semantic domain.

## 10. Universal Runtime

The governed execution route is:

`identity → authority → policy → capability → resource → dependency → execution → state transition → event → audit`

Implementation providers, persistence, transport and infrastructure remain replaceable beneath the contracts.

**IO** provides governed input/output/exchange boundaries.

**HAPI** provides the human connection and continuity boundary.

The former proposed **ECC (Execution Coordination Center)** is NOT a required infrastructure dependency. OMNII coordination is provided by the universal runtime, workflow/execution contracts, IO, authorized agents and ABBA as orchestration. Any paid/proprietary ECC service or vendor dependency is explicitly excluded from the constitutional architecture. An equivalent function may be implemented with ordinary code, open protocols, queues, schedulers, workers and authorized agents without creating a proprietary architectural dependency.

## 11. Universal Composition Layer

OMNII provides reusable composition contracts for arbitrary real-world situations without adding a new constitutional kernel for each domain.

The detailed contract is defined in `OMNII_UNIVERSAL_COMPOSITION.md` and includes:

- Situation;
- Schema/Form;
- Time/Calendar;
- Workflow;
- Policy/Rule;
- Decision;
- Case;
- Evidence/Proof;
- Resource Planning;
- Capacity;
- Availability/Reservation;
- Commitment/Obligation;
- Reporting;
- Simulation;
- Localization/Variation;
- Exception/Unknown handling.

These are composition services/contracts built on canonical objects, relationships, authority, governance, events, state, capability, resource, value, continuity and integration. They do not redefine the foundational semantics.

## 12. Human Layer

People are canonical participants with identity, agency, consent, authority, relationships and continuity. Human authority cannot be silently substituted by agent optimization.

## 13. Organization and Institution Layer

Organizations and institutions compose canonical objects with mandates, roles, membership, resources, policies, services, accountability and lifecycle.

## 14. Territory Layer

Territories compose people, institutions, infrastructure, resources, services, economy, events and governance subject to applicable law and jurisdiction.

## 15. Ecosystem / World Layer

Ecosystems and worlds are higher-order compositions of people, organizations, products, communities, territories, institutions, infrastructure, agents, services and resources. Phase 21–40 belongs here. Local autonomy remains real; shared substrate does not imply shared authority.

## 16. Floor — Operational Reality

The Floor is where constitutional objects and capabilities encounter lived reality: finance, education, government, agriculture, healthcare, property, elections, logistics, employment, commerce, infrastructure, community activities and physical-world operations.

Consequential Floor activity should remain traceable to identity, authority, policy, capability, resource, execution, state, evidence and audit as applicable.

## 17. Operating Law

A cross-cutting design heuristic remains:

`ROLE + ROUTE + RETURN + BOUNDARY + STATE`

Every consequential component/composition should make responsibility, movement of work/data/authority, feedback/result, boundaries and state change explicit.

## 18. Infrastructure Boundary

Technical infrastructure implements OMNII; it does not define constitutional meaning.

The implementation boundary may use identity systems, passkeys, DNS/HNS/ENS/DID/VC mechanisms, policy engines, secrets, encryption, event buses, workflow engines, queues, schedulers, communication routers, ledgers, payment rails, analytics, search, marketplaces, evidence systems and physical-world integrations.

Provider selection is replaceable. No paid/proprietary service is a constitutional dependency.

## 19. Products and Services

Products are manifestations of OMNII. They compose universal objects and capabilities and MUST NOT redefine constitutional primitives.

**Emirati** is therefore a product/ecosystem composition that consumes OMNII universal composition capabilities. Sallah Gani, Eid, weddings, funerals, trade fairs, family visits, emergencies, horse/rider commerce, hospitality and other activities are configurations/deployments of the same substrate, not separate constitutional architectures.

## 20. Phase Architecture

Phase 21–40 remain layered above the constitutional/runtime substrate. Later phases may provide ecosystem, self-audit, evolution, human/institution/territory/civic and inter-world compositions, but may not silently redefine the foundational contract.

Phase 41 is not currently defined by this repository.

## 21. Conformance Principle

A new real-world requirement is handled in this order:

`compose existing primitives → configure schema/policy/workflow → extend a domain composition → record evidence → propose constitutional amendment only if a genuine foundational semantic is missing`

This makes the ecosystem adaptive without making the foundation unstable.
