## Conformance rule

Before implementing an institution-specific requirement:

1. Search the universal registry/capability shelf.
2. Reuse an existing capability if semantically sufficient.
3. Configure forms, workflows, policies and UI before writing bespoke logic.
4. Extract recurring patterns into reusable modules.
5. Keep local law, institutional authority, data and policy at the configuration/domain boundary.
6. Version every deployable shared component.
7. Produce an explicit handoff/exit package.

## Strategic rule

Every reference deployment should leave OMNII stronger than it found it. A successful institutional implementation is both a customer solution and a source of validated reusable capability.
