# RELATIONSHIP REGISTRY

The Relationship Registry is the canonical registry of permitted and observed relationships among OMNII objects.

## Purpose
Make connection semantics explicit, queryable, auditable, and composable.

## Relationship Classes
- Identity
- Membership
- Ownership
- Association
- Dependency
- Trust
- Commitment
- Delegation
- Exchange
- Communication
- Governance
- Composition

## Required Relationship Properties
- Relationship ID
- Source object
- Relationship type
- Target object
- Authority
- Status
- Effective period
- Provenance
- Constraints

## Invariant
A relationship is not merely a link; it carries semantic meaning, authority, provenance, and lifecycle.
