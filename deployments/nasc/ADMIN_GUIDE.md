# NASC Administrator Guide

Administrators manage institutional configuration, users, roles, integration endpoints and reference data. Production statutory rules and controlled lists should be changed only through NASC-authorized change control.

## Administration boundaries

Admins may configure users, non-authority metadata, form availability, workflow assignment and integrations within delegated permissions. Admins must not self-approve consequential licensing, certification or enforcement decisions.

## Reference data

Load crop/variety codes, regions, fee schedules, licence classes, laboratory scopes and other controlled data through versioned change control. Every update should have an owner, effective date, source and audit record.

## Release management

Promote versioned NASC configuration as a unit. Verify migration version, manifest version and configuration version match before activation.
