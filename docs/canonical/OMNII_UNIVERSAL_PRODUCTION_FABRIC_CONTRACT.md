## 7. Governance Invariants

- Human authority remains explicit.
- Agent authority is bounded and revocable.
- Data access is permissioned and provenance-aware.
- Generated UX cannot redefine canonical semantics.
- Completion requires evidence and dependency resolution.
- Integration is preferred to duplication.
- Providers are replaceable.
- Unknowns remain unknown until resolved.
- Failures become recoverable states.
- Production behavior remains observable.
- Value and money remain distinct.
- Local implementations remain configurations of global capabilities.
