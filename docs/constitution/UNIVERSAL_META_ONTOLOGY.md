# OMNII Universal Meta-Ontology

**Status: CANONICAL CONSTITUTIONAL CONTRACT**

## Purpose

The Universal Meta-Ontology defines how OMNII can represent a thing it did not previously know how to represent.

It is the constitutional mechanism that preserves the ecosystem's **stateless, formless and open-world** character. It does not attempt to enumerate every possible entity, species, technology, phenomenon, relationship or economic instrument. Instead, it defines the rules by which new kinds can be introduced, tested, connected, versioned, governed and eventually retired.

## Core rule

> **No new product may require the constitutional core to be rewritten merely because a genuinely new kind of thing has appeared.**

A new kind may be represented provisionally first. Canonical status is earned through evidence, compatibility, governance and demonstrated need.

## Unknown-first principle

When a phenomenon does not fit an existing type:

```text
Unknown / observed object
        ↓
Provisional description
        ↓
Hypotheses / candidate classifications
        ↓
Evidence and provenance
        ↓
Relationship discovery
        ↓
Capability/resource/value implications
        ↓
Governed promotion OR remain provisional
```

OMNII MUST NOT force an unknown object into the nearest familiar category merely to satisfy a schema.

## Type lifecycle

```text
PROPOSED
  ↓
PROVISIONAL
  ↓
EMERGING
  ↓
CANONICAL
  ↓
SUPERSEDED / DEPRECATED
  ↓
RETIRED
```

A type may also be rejected, withdrawn or forked. Historical records retain the type/version that was valid when the record was created.

## Versioning

A type has both structural and semantic versions. Changes are classified as:

- compatible extension
- compatible clarification
- breaking structural change
- breaking semantic change
- correction of error
- supersession by a new type

Historical reality is never silently reinterpreted because the current type changed.

## Mapping

A new type may map to:

```text
existing OMNII type
external standard
external identifier system
industry taxonomy
legal classification
scientific taxonomy
local/community vocabulary
other namespace
```

Mappings are contextual assertions, not identity erasure. Multiple mappings may coexist and may conflict.

## Constraints and invariants

A type declaration may define:

- required fields
- optional fields
- cardinality
- allowed states
- valid transitions
- relationship constraints
- temporal constraints
- authority constraints
- evidence requirements
- safety constraints
- privacy constraints
- economic constraints
- interoperability requirements

Constraints govern representations and actions; they do not become claims about reality without evidence.

## Emergence

OMNII explicitly supports emergent entities and phenomena:

```text
interactions
→ repeated pattern
→ observed emergent behavior
→ provisional object
→ candidate type
→ governed classification
```

The ecosystem may discover a new capability, relationship, collective, species, market, protocol or phenomenon that no designer anticipated.

## Multi-species and multi-intelligence compatibility

The meta-layer must not assume human biology, human cognition, human language, human embodiment or human social organization.

A new participant class may specify its own:

- embodiment
- sensory modalities
- cognition
- communication
- reproduction/replication model
- habitat
- resource requirements
- agency model
- representation model
- rights/welfare/authority model
- continuity model

Unknown biological, artificial, collective or extraterrestrial participants can therefore enter provisionally without being reduced to a human template.

## New economic dimensions

A newly discovered resource or value dimension can be declared independently, for example:

```text
new physical resource
new energy form
new information resource
new ecological capacity
new cognitive capability
new social contribution
new temporal capacity
new scarcity dimension
new tokenized right
new settlement unit
```

The new dimension must retain its raw measurement, valuation method, context and provenance. It must not be silently folded into money.

## New technologies and protocols

A new technology is an integration/capability candidate, not automatically a constitutional primitive.

Examples include future:

- naming systems
- identity systems
- ledgers
- blockchains/DLTs
- communication protocols
- AI systems
- sensors
- space systems
- settlement systems

OMNII records what the technology enables, what it controls, what evidence it produces, its authority boundary and how it maps to existing primitives.

## Governance of extension

Promotion to canonical status requires:

1. clear semantic definition;
2. evidence/provenance;
3. compatibility analysis;
4. boundary analysis;
5. authority and security review;
6. scenario coverage;
7. quality/completeness assessment;
8. migration/version strategy;
9. explicit governance decision.

ABBA may discover, propose, model and test extensions but does not obtain constitutional authority merely by generating them.

## Anti-forcing rule

The following are prohibited:

- inventing a familiar classification to eliminate uncertainty;
- silently changing the meaning of an existing type;
- treating a product schema as ontology;
- treating an external standard as OMNII truth;
- treating a name, token, credential or address as the underlying reality;
- making an implementation limitation a constitutional limitation;
- deleting history because a type was superseded.

## Meta-ontology and the constitutional core

The meta-layer is deliberately small. It governs **how the ontology grows** rather than becoming another exhaustive ontology.

```text
CONSTITUTIONAL CORE
        ↓
META-ONTOLOGY
        ↓
NEW TYPE / RELATION / RESOURCE / CAPABILITY / EVENT
        ↓
PRODUCT COMPOSITION
```

Products remain compositions. New products do not create private ontologies that contradict the canonical model.

## Final invariant

> **OMNII must be able to represent the existence of something before it knows what that something is.**

That is the constitutional condition for a genuinely open-world, stateless and formless ecosystem.
