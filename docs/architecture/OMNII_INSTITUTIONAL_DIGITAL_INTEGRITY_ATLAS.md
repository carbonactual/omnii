## Integrity lifecycle

```text
inventory → ownership → baseline → monitor → detect → classify → contain → investigate → remediate → verify → close → learn
```

Detection classes include unauthorized content, SEO spam, gambling/casino injection, suspicious redirects, phishing indicators, unexpected DNS changes, certificate changes, credential misuse, unexplained deployments, stale or abandoned assets, unowned subdomains, exposed interfaces and integrity failures.

## Boundary

This module provides governance, monitoring and evidence infrastructure. It does not confer cyber, police, military or regulatory authority. Institutionally authorized actors remain responsible for consequential response decisions.
