# OMNII IDENTITY RUNTIME

Identity is the runtime answer to **Who is this?**

## Identity Contract
A subject has a stable identifier, subject type, credentials or attestations, lifecycle, provenance, and links to recognized representations.

## Runtime Functions
`resolve → authenticate → attest → correlate → suspend/revoke → recover`

Identity is distinct from capability, ownership, authorship, and authority. Correlation must not merge distinct identities without explicit evidence.
