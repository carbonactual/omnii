# OMNII Institutional Opportunity, Workforce, Promotion & Deployment Atlas

**Status: CANONICAL REUSABLE DOMAIN ATLAS**

## Opportunity families

Tender; grant; scholarship; vacancy; job; contract opportunity; partnership; sponsorship; membership; investment; referral; service opportunity; procurement opportunity; programme opportunity.

Every opportunity can carry eligibility, opening/closing time, authority, capacity, application form, evidence requirements, evaluation method, decision path, notifications, commitments and outcome.

## Workforce lifecycle

```text
establishment/vacancy → application → screening → assessment → interview → recommendation → approval → appointment → onboarding → capability/credential → performance → progression → separation
```

## Promotion lifecycle

```text
eligibility → service record → qualification → capability → performance evidence → vacancy/establishment → nomination/recommendation → conflict/eligibility checks → authorized approval → effective date → notification → posting → appeal/review → audit
```

## Deployment lifecycle

```text
readiness → selection → assignment → authority → logistics → deployment → execution → status updates → relief/return → debrief → evidence → expenditure reconciliation → closeout
```

## Reusable registries

Applicant; staff; member; contractor; consultant; volunteer; vacancy; position/establishment; skill; capability; credential; training; attendance; performance; recognition; promotion; posting; deployment; transfer; leave; roster; availability; duty; disciplinary matter; separation/exit; opportunity; nomination; recommendation; appointment; succession.

## Controls

No promotion or deployment is valid merely because an automation recommends it. High-consequence employment, command, security and access changes retain required institutional authority and approval. Conflicts, duplicated appointments, expired credentials, unavailable personnel, over-capacity assignments and unauthorized postings become exceptions/cases.

## Universal links

Person → identity → capability → credential → availability → opportunity/vacancy → application → workflow → assessment → decision → authority → appointment/promotion/deployment → execution → evidence → performance → Pulse.

## Portability

The same engine supports civil service, schools, universities, police, defence organizations, hospitals, NGOs, clubs and private employers with different policies, authority matrices and domain modules.
