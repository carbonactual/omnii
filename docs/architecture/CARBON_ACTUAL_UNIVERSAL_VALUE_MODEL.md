# OMNII Universal Value Model

**Status: CANONICAL CONTRACT**

Value is a governed relation between a subject, an object/resource, a context, an authority model and an observable outcome. Value is not synonymous with money.

## Value dimensions

The universal model can represent economic, social, informational, capability, time, trust, contribution, ecological and other registered value dimensions without forcing them into one unit.

## Core distinctions

`value ≠ price ≠ money ≠ asset ≠ resource ≠ ownership ≠ contribution ≠ obligation`

Implementations may introduce units, valuation methods, markets and settlement mechanisms, but must preserve these distinctions.

## Governance

Value creation, transfer, allocation and destruction are subject to authority, provenance, policy and audit. Tokenization, fractionalization, decimalization, decentralization and other economic mechanisms are implementation/composition patterns constrained by this model.

## Reuse

Every product or institution inside OMNII consumes the same value semantics. A domain may specialize valuation without creating a competing universal economic ontology.
