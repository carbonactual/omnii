# OMNII Alternative Assets, Digital Assets & Collectibles

**Status:** Draft Canonical / Extension to Global Value, Finance & Payment Network  
**Parent:** `docs/FINANCIAL_VALUE_NETWORK.md`

## Purpose

The OMNII financial/value ontology must cover legitimate forms of scarce, collectible, alternative, cultural, luxury, digital, computational and productive value that are commonly omitted from ordinary banking systems.

These objects remain distinct from money. Their economic value may derive from utility, scarcity, provenance, ownership rights, access rights, cultural significance, collectability, productive capacity, contractual claims, or market demand.

```text

├── location
```

## 3. Provenance and Authenticity

For collectibles, art, rare books, jewelry and other scarce assets, provenance is a core value attribute rather than optional metadata.

The system may record:

- Creator/maker
- Date/era
- Edition/printing
- Serial or identifying marks
- Previous owners
- Chain of custody
- Auction/sale history
- Certification
- Assay
- Expert appraisal
- Conservation/restoration
- Damage/repair history
- Import/export history
- Legal restrictions
- Photographic/documentary evidence

Where blockchain is used, an on-chain record is treated as evidence or representation, not automatically as proof of legal title to an underlying physical object.

## 4. Specialist Valuation

Valuation methods are asset-specific and may combine:

- Market comparables
- Auction history
- Rarity
- Condition
- Provenance
- Material/content value
- Replacement cost
- Income/royalty potential
- Utility
- Scarcity
- Demand
- Expert appraisal
- Certification
- Independent verification

The system should support multiple simultaneous values rather than forcing one universal price:

```text
RETAIL VALUE
WHOLESALE VALUE
AUCTION ESTIMATE
LIQUIDATION VALUE
INSURANCE VALUE
COLLATERAL VALUE
REPLACEMENT VALUE
MATERIAL VALUE
COLLECTOR VALUE
PULSE / UTILITY VALUE
```

These are different measurements and must not be silently substituted for one another.

## 5. Ownership, Custody and Rights

The ontology distinguishes:

- Physical possession
- Custody
- Legal ownership
- Beneficial interest
- Lien/encumbrance
- Usage rights
- Display rights
- Licensing rights
- Reproduction rights
- Royalty rights
- Redemption rights
- Token representation

A token, certificate, warehouse receipt or custody record is not automatically the same thing as legal ownership of the underlying asset.

## 12. Open-Ended Asset Registry

No fixed list should define the complete universe.

A new asset class can be registered by defining:

`class + identity + unit + rights + evidence + valuation model + lifecycle + restrictions + permitted exchanges + financing eligibility + jurisdictional treatment`

This allows the ecosystem to incorporate new technology, new markets, new collectible categories, new financial instruments and new forms of economic value without redesigning the foundational ontology.

```text
        ↓

        ↓

        ↓

        ↓
```

This extension inherits the parent Financial Value Network doctrine: money is one representation of value; payment is one settlement mechanism; finance is one class of relationships around value; and the ontology remains extensible for future forms of value.
