# OMNII Vendor Independence

**Status: CANONICAL HARDENING**

No paid or proprietary product is a constitutional dependency of OMNII.

Optional providers may be connected through replaceable adapters only when the same constitutional semantics remain valid without that provider.

This applies to orchestration, workflows, databases, identity providers, messaging, payments, search, analytics, AI providers, maps, media, event systems and other implementation services.

For execution coordination specifically, OMNII uses composition of workflow execution, scheduling, queues/event delivery, authorized workers/agents, IO/integration, policy checks, state transitions, evidence/audit and human escalation. A product named ECC is neither required nor foundational.

The removal principle is simple:

`capability is universal; provider is replaceable.`
