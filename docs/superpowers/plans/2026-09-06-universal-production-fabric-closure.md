# Universal Production Fabric Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the missing production-fabric capabilities required for Carbon Actual to turn arbitrary ideas and observed reality into governed, executable, observable and continuously improving products, services, institutions, workflows, agents and worlds.

**Architecture:** Extend the existing ten-family ontology with reusable capability contracts rather than adding constitutional families. The fabric links Universal Composition, Experience Compilation, Agent Control, Data/Context/Memory, Execution/Integration, Evaluation/Release, Deployment/Lifecycle and Observability/Pulse while preserving human authority, provider independence and global-by-default semantics.

**Tech Stack:** Canonical Markdown architecture, existing OMNII runtime/common-layer contracts, replaceable implementation providers, global standards and protocol adapters.

**Spec:** `docs/canonical/OMNII_UNIVERSAL_PRODUCTION_FABRIC_CONTRACT.md`

## Global Constraints

- Products remain compositions of shared capabilities; do not create product-specific foundational semantics.
- Existing ten constitutional families remain the architecture boundary.
- Global is the default; geography, law, language, infrastructure and provider selection are configuration/context.
- Human authority is explicit and consequential actions remain governed.
- Unknown and ambiguous inputs remain valid states; do not force classification.
- Integration is preferred to duplication and providers remain replaceable.
- Generated UI cannot redefine canonical identity, authority, value, provenance or governance.
- Completion requires evidence, dependencies, security, observability and lifecycle state—not merely an artifact or screen.
