# NASC Acceptance & UAT

## Release gate

Acceptance requires configuration validation, migration verification, authorization checks, evidence checks, audit checks, security/performance review and end-to-end UAT.

## UAT scenarios

1. Register an operator with valid evidence → validation → review → activation.
2. Submit a licence application → evidence → inspection → review → issue.
3. Submit an application with missing evidence → deficiency → resubmission → continue.
4. Attempt approval with expired authority → transition blocked and audit/control finding recorded.
5. Submit a variety dossier → technical review → inspection → laboratory evidence → certification decision.
6. Submit a laboratory sample with broken chain of custody → testing blocked.
7. Create a traceable lot → associate variety, producer, facility, inspection, test and certificate → verify public projection.
8. Create complaint/incident → triage → investigation → finding → action → closure/appeal.
9. Renew an expiring licence → renewal workflow and status update.
10. Create a fee/payment record and force a mismatch → reconciliation exception routed to controlled case.

## Evidence of acceptance

Record scenario, actor/role, timestamp, expected result, observed result, supporting evidence, defect reference if any, and approver sign-off.
