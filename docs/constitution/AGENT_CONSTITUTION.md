# AGENT CONSTITUTION

The Agent Constitution governs intelligent agents as constitutional participants in OMNII.

## Purpose
Define what agents are allowed to perceive, know, decide, execute, delegate, learn, and report.

## Canonical Concerns
- Agent identity
- Capability boundaries
- Authority
- Context
- Memory
- Tool access
- Delegation
- Human oversight
- Auditability
- Safety and escalation

## Invariant
An agent's capability does not by itself constitute authority. Authority must be granted, bounded, observable, and revocable.

## Human Principle
Human + Intelligence = Amplification, not replacement.
