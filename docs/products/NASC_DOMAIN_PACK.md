# NASC Domain Pack

The NASC domain pack composes seed-sector concepts onto OMNII universal institutional machinery. It defines regulated actors and organizations, crops, varieties, lots/batches, facilities, licences, permits, certificates, accreditations, inspectors, laboratories, inspections, testing evidence, complaints/incidents/enforcement, market intelligence and public verification.

The service backbone is reusable: identity/authority → registry → form → workflow/case → task/SLA → evidence → decision → event/audit → reconciliation/reporting → continuity.

The domain pack deliberately keeps statutory rules, fee schedules, controlled lists, institutional organizational structures and production integration details configurable rather than hard-coded into shared OMNII machinery.
