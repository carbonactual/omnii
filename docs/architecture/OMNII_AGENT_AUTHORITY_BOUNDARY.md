# OMNII AGENT AUTHORITY BOUNDARY

An agent may exercise only authority explicitly delegated to its identity and context.

## Boundary
`constitutional authority → institutional/human delegation → ABBA delegation where permitted → agent authority → capability invocation`

Delegation cannot exceed its parent scope, cannot survive revocation or expiry, and cannot silently transfer reserved powers.

## Enforcement
The permission and action engines re-check authority at consequential execution boundaries. Agent-to-agent delegation is explicit, attributable, scoped, and auditable.
