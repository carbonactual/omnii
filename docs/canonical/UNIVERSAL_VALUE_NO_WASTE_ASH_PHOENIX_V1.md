# Universal Value / No-Waste / Ash / Phoenix Fabric v1

## Purpose

Provide one reusable economic, operational and security fabric for Carbon Actual products and domains.

## Value

Value is contextual and evidence-backed. Money is one representation of value, not the sole definition of value. Value may arise from capability, time, energy, resources, knowledge, access, rights, outcomes, risk reduction, continuity, service, physical assets or other governed economic effects.

## Inverted economics

Asset/liability status is not assumed from the object name. It is derived from the direction and quality of value consequences in context. A resource can become an asset or liability as context, cost, capacity, risk, time, depreciation, opportunity and Pulse change.

Conceptually:

`net_effect = value_returned - value_consumed - risk_adjustment - continuity_cost`

The formula is an architectural placeholder for explainable component models, not a universal monetary score. Every production valuation must preserve units, time, evidence, provenance and jurisdiction.

## No Waste

No useful economic, physical, digital, knowledge or capability resource should be discarded merely because its previous use ended. Residual value is evaluated for reuse, repair, redistribution, transformation, recovery, learning, substitution or safe containment.

## Ash

Ash represents residual, exhausted, unsafe, non-value or transformed state that remains part of provenance and security context. Ash is not silently deleted history.

## Phoenix

Phoenix is the active recovery/regeneration lifecycle: detect, contain, assess, recover, restore, verify, learn and re-enter service where safe. Phoenix does not bypass authority or evidence requirements.

## Pulse

Pulse provides feedback from operation: performance, cost, reliability, value return, risk, continuity, quality and other context-specific signals. Pulse updates future curation; it does not itself create authority.

## Proof and Actual

Proof records evidence that a claim or action occurred. Actual records the governed formed operational state. Financial recognition or public publication requires the applicable authority and policy gates.

## IO and settlement

I/O carries movement, interaction, application, execution and settlement pathways. It must remain provider-neutral and support non-financial, sandbox and regulated adapter states without pretending that registration equals activation.

## Ecosystem loop

`capability/resource → use → outcome → Proof → Actual → Pulse → Value assessment → asset/liability state → settlement/ledger → residual/Ash → Phoenix/recovery → learning`

All products consume this fabric through stable contracts. No product may define a competing global economic or security constitution.
