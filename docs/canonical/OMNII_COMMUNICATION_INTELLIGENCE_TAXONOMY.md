# OMNII Communication Intelligence Taxonomy

**Status:** CANONICAL CAPABILITY TAXONOMY
**Parent:** `docs/canonical/OMNII_COMMUNICATION_PRESENCE_FABRIC.md`
**Scope:** Full historical, contemporary, biological, human, machine, environmental, intelligence, accessibility, emerging and future communication universe
**Intelligence:** ABBA orchestration
**Purpose:** Prevent omissions, competing primitives and product-specific reimplementation of communication intelligence.

## 1. Canonical principle

Communication is broader than language, messaging, networking or human conversation.

The ecosystem treats communication as any observable or exchanged signal, representation, behavior, state, artifact, protocol or interaction by which information can be expressed, transmitted, received, inferred, interpreted, verified, transformed or acted upon.

The canonical object is not the transport. It is the governed communication relationship and its observable/interpretable signal.

Therefore:

```text
IDENTITY / ENTITY / ENVIRONMENT
→ CAPABILITY TO EXPRESS
→ SIGNAL / REPRESENTATION
→ CONTEXT / MEDIUM / TRANSPORT
→ PERCEPTION / RECEPTION
→ INTERPRETATION
→ VERIFICATION / CONFIDENCE
→ RESPONSE / ACTION
→ RECORD / PROVENANCE
→ CONTINUITY / FEEDBACK
```

Observation must remain distinct from interpretation. An observed signal is not automatically an established meaning.

## 14. Code, cipher, encoding, symbol and protocol

The intelligence layer must distinguish:

**Language** — the linguistic/semantic system.

**Code** — a mapping or convention for representing information.

**Cipher** — a transformation intended to conceal or protect information through a cryptographic system.

**Encoding** — representation in another technical or conventional form without implying secrecy.

**Symbol system** — meaning assigned through convention or culture.

**Protocol** — rules governing interaction/exchange.

**Signal** — an observable carrier used to convey information.

**Notation** — structured representation used for a domain.

**Steganographic/concealed content** — information hidden within a carrier.

A decoder must first identify the class before selecting an interpretation.

## 15. Communication intelligence workflow

```text
OBSERVE
→ CAPTURE
→ NORMALIZE
→ DETECT SIGNAL
→ CLASSIFY MODALITY
→ IDENTIFY POSSIBLE SYSTEM
→ IDENTIFY CONTEXT
→ IDENTIFY ENCODING / CODE / CIPHER / PROTOCOL
→ DECODE / TRANSCRIBE / TRANSLATE WHEN AUTHORIZED
→ CORRELATE
→ CHECK PROVENANCE
→ ESTIMATE CONFIDENCE
→ PRESERVE ALTERNATIVES
→ INTERPRET
→ RESPOND / ESCALATE
→ RECORD
```

The system must preserve:

- raw observation;
- derived signal features;
- candidate interpretations;
- rejected hypotheses where useful;
- confidence;
- source/evidence;
- time/location context when authorized;
- operator/model transformations;
- final interpretation;
- downstream action.

## 20. Communication as sensing and sensing as communication

Communication and sensing may be coupled.

The ecosystem may treat authorized sensor observations as communication from the environment or machine to an intelligence layer. Conversely, communication infrastructure may provide sensing information.

ITU's current IMT-2030 work explicitly treats immersive communication, AI-and-communication and integrated sensing and communication as distinct future network scenarios, while recent ITU technical work describes joint sensing/communication workflows, authentication, capability exposure, node selection, data fusion and collaborative sensing. cite-as-research-anchor:ITU-ISAC

This creates a canonical boundary:

**sensing data is not automatically a message, but it can be a communication input when modeled and authorized as such.**

## 34. Major loopholes closed by this taxonomy

This taxonomy explicitly prevents the following omissions:

1. Treating communication as only text/voice/video.
2. Treating sign language as mere gesture.
3. Ignoring deafblind/tactile communication.
4. Ignoring AAC and non-speaking participants.
5. Ignoring infants and pre-linguistic communication.
6. Ignoring animal and interspecies signalling.
7. Ignoring environmental and machine signals.
8. Ignoring diplomatic, legal, military and intelligence domains.
9. Ignoring emergency/public-warning communication.
10. Confusing a signal with its meaning.
11. Confusing language, code, cipher, encoding and protocol.
12. Treating transport as the communication primitive.
13. Treating presence as identity.
14. Treating discoverability as permission to contact or track.
15. Treating incognito as destruction of canonical identity.
16. Treating a cloned representation as the original person.
17. Treating AI-generated content as provenance-free.
18. Treating tracking as a default right.
19. Treating all telemetry as communication or all communication as telemetry.
20. Ignoring ambiguity, uncertainty and competing interpretations.
21. Ignoring translation and modality-conversion loss.
22. Ignoring noise, interference and degraded connectivity.
23. Ignoring covert-channel indicators and adversarial signaling.
24. Ignoring human escalation.
25. Treating every communication as globally reusable memory.
26. Forcing future/experimental technologies into present production.
27. Building isolated communication primitives inside individual products.

## 35. Ecosystem boundary

This taxonomy does not create separate application-level communication systems.

It defines the shared semantic and capability space from which products and operating environments consume communication functions.

NOUN Bot, HAPI World, NAIRE, NGIN, RITES and other products/environments may specialize workflow, UI, audience and domain behavior, but the common communication, accessibility, presence, decoding, provenance, routing, security and continuity capabilities remain ecosystem-owned and orchestrated by ABBA.
