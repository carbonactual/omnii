# NASC User Guide

## Applicant / operator

Start with the relevant registration or application form. Provide required evidence. Track status and respond to deficiency requests. A licence/certificate is not considered active until the governed process reaches the authorized issued/certified state.

## Inspector

Open assigned inspections, verify scope and authority, capture field evidence, submit the inspection report and respond to follow-up tasks.

## Laboratory

Accept only assigned samples within approved scope. Verify chain of custody, capture method/result evidence and complete quality review requirements.

## Reviewer / approver

Review the case record and required evidence. Decisions must be made within delegated authority and must be recorded through the workflow so the audit trail remains complete.

## Public user

Use public verification with the official identifier. Only non-sensitive verification information is returned.
