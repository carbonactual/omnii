# OMNII OBJECT REGISTRY

The authoritative runtime index of canonical objects.

## Registration
Requires canonical object schema validation, unique identity, schema compatibility, lifecycle validity, authority, and provenance.

## Operations
`register | resolve | validate | update | supersede | suspend | retire`

## Guarantees
Identity remains stable; active versions are immutable; changes are attributable; invalid objects cannot become canonical by registration alone.

## Query
Resolution supports type, identifier, version, status, authority, provenance, and relationship/dependency constraints.
