# NASC Operations Runbook

## Daily

Review new submissions, validation failures, overdue tasks, inspections, laboratory turnaround, expiring authorizations, control findings and reconciliation exceptions.

## Case execution

All consequential work follows the configured workflow. Staff should never bypass a required evidence or authority gate. Deficiencies are returned through the workflow; they are not silently overwritten.

## Inspection

Schedule → assign an authorized inspector → field execution → evidence/report → supervisory review → accept/follow-up → close.

## Testing

Receive sample → verify chain of custody → test → record result → quality review → accept/reject → certificate decision where applicable.

## Licensing

Validate application → confirm required evidence → inspect where required → review → authorized decision → issue → renewal monitoring. Suspension/cancellation must be auditable.

## Exceptions

Urgent-risk matters, expired authority, conflict of interest, broken sample chain, missing evidence, duplicate identities and payment mismatches are routed to controlled cases and must retain evidence.

## Incident response

Preserve evidence, restrict affected records where authorized, create a control/case record, assign an owner, remediate, document resolution and retain the audit trail.

## Recovery

Follow the institution's Supabase backup/recovery policy. Restore into a controlled environment, verify schema/configuration versions, validate audit continuity, run UAT smoke tests, then return to service.
