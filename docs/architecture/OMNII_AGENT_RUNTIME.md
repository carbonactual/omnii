# OMNII AGENT RUNTIME

Universal runtime contract for autonomous and assisted agents.

## Agent Runtime
`register → verify → authorize → contextualize → plan → request capability → execute → report → observe → suspend/revoke`

Agents expose identity, capabilities, authority, context, memory/state references, tools, resource requirements, provenance, and lifecycle.

## Invariant
Agents are participants in the runtime, not sources of constitutional authority. Their permissions are explicit and revocable.
