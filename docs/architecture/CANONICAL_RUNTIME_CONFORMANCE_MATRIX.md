## Gate policy

A conformance failure is classified before remediation as:

- constitutional conflict;
- contract conflict;
- implementation regression;
- capability duplication;
- domain-boundary violation;
- provider/adaptor failure;
- unresolved unknown.

No implementation fix may solve a constitutional conflict by rewriting the constitution. Constitutional changes require the explicit amendment process.
