# OMNII RELATIONSHIP REGISTRY

Runtime registry for typed relationships between canonical objects.

## Operations
`register → validate → resolve → activate → observe → supersede → retire`

Endpoints must resolve to addressable objects or declared external contracts. Relationship type, direction, authority, constraints, effective dates, and provenance are validated.

## Invariants
Authority, ownership, dependency, and governance semantics cannot be inferred from an untyped link. Historical relationships remain auditable.
