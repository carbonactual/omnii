# OMNII Architectural Invariants

These statements are intended to become automated contract tests.

1. Every canonical object has a stable identity and canonical type.
2. Every consequential object has provenance sufficient for audit.
3. Every consequential relationship identifies source, target and relationship type.
4. Authority is scoped, attributable, time/context aware where required, and revocable.
5. Capability never implies authority.
6. Intelligence never implies authority.
7. Orchestration never implies ownership.
8. Planning never implies execution.
9. An action/command does not prove execution occurred.
10. An event records an occurrence; it does not substitute for state.
11. State transitions are attributable and observable.
12. Queries do not mutate canonical state.
13. Every consequential execution is attributable to an actor and authority context.
14. Cross-boundary execution requires explicit compatible authority/agreement.
15. Constitutional kernels do not depend on products.
16. Constitutional kernels do not depend on specific agents.
17. ABBA cannot self-create constitutional authority.
18. ABBA cannot exceed delegated authority.
19. Products cannot redefine canonical object semantics.
20. Phase 21–40 extensions cannot redefine the canonical graph.
21. Dependencies are semantically distinct from ordinary relationships.
22. Registry sharding cannot create competing semantic definitions.
23. Economic transactions are auditable and attributable.
24. Value, money, resource, asset, ownership, contribution, price and cost remain semantically distinct.
25. Historical architecture may remain for provenance but cannot silently compete with canonical sources.
26. A future/horizon component is not implementation-ready solely because source code exists.
27. A missing phase implementation is reported as a gap rather than inferred into existence.
