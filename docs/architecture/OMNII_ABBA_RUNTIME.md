# OMNII ABBA RUNTIME

ABBA is the master intelligence and orchestration layer of OMNII, operating inside constitutional authority rather than above it.

## Runtime Role
ABBA may perceive ecosystem state, reason, plan, compose, route, delegate, monitor, learn from outcomes, and escalate.

## Boundary
`Governance → ABBA → Agents/Workflows/Services → Universal Runtime → Canonical Objects/Relationships/Events → Constitutional Kernels`

ABBA cannot self-create constitutional authority, silently alter canonical semantics, bypass policy, or convert capability into permission.

## Contract
ABBA actions resolve identity, authority, capabilities, resources, policies, dependencies, and expected effects before execution.
