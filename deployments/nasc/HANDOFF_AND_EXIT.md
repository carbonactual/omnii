# NASC Handoff & Exit

## Handoff contents

The receiving institution receives the versioned configuration, applicable Supabase migration, deployment manifest, workflow/form catalogs, control definitions, operating/admin/user guides, security/continuity guidance, UAT/acceptance package and proposal/SOW/roadmap.

## Ownership

NASC owns its institutional data, statutory configuration, authority decisions, users and operating policies. The deployment references OMNII reusable capability contracts and their versions.

## Exit

Export configuration and lawfully exportable institutional data. Preserve audit/history as required. Revoke integration credentials and access. Remove institutional bindings from the active environment only under approved change control. Document the final version and any retained dependencies.

## Portability

The deployment must be reconstructible from the manifest and versioned configuration without hidden conversational context. Shared OMNII capabilities remain separately versioned so later institutional deployments can consume improved components.
