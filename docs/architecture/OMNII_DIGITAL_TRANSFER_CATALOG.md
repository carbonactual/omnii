## Required transfer questions

For every material transfer, the body should be able to answer when evidence exists:

1. **Who initiated it?**
2. **For whom?**
3. **Under whose authority?**
4. **What was requested?**
5. **What was actually transferred or exposed?**
6. **From where?**
7. **To where?**
8. **Why?**
9. **Under what policy/terms?**
10. **Was human approval required?**
11. **Was approval actually given?**
12. **What changed during transfer?**
13. **What evidence proves it?**
14. **What copies or derivatives were created?**
15. **Who can access the result now?**
16. **When does that access expire or become revocable?**
17. **What happens on deletion, cancellation, recovery or exit?**

## Access levels

The body should distinguish at least:

`discover → metadata → preview → read → write → append → modify → execute → share → export → delete → administer → delegate`

A capability at one level MUST NOT silently imply every higher level.

## User mediation

High-impact transfers SHOULD use explicit, comprehensible mediation. A user should see the target, scope, purpose, recipient, consequence and duration before approval where policy/risk requires it.

## Evidence

Transfers should generate universal events and evidence sufficient to reconstruct the boundary crossing without retaining unnecessary secrets or sensitive content.

## Security

URLs, files, images, media, documents, downloaded artifacts, remote responses, browser state, advertisements and retrieved AI context are untrusted inputs until validated under the existing security law.

## No new primitive

The catalog is coverage only. Transfer remains an interaction expressed through the existing universal dimensions, events, evidence, provenance, dependency, authority, settlement, liability and lifecycle.
