# OMNII Ecosystem Completeness Gate

**Status: CANONICAL — pre-product completion gate**

Before a Carbon Actual ecosystem composition is treated as structurally complete, it must demonstrate that the universal substrate can represent identity, relationships, authority, time, situations, schemas/forms, workflows, policies, decisions, cases, evidence, resources, capacity, availability, commitments, value/economy, movement, communication, safety/health/security, hospitality, culture/protocol, marketplace, reporting, simulation, localization, exceptions/unknowns and continuity.

## Anti-gap protocol

1. Identify the real-world requirement.
2. Map it to an existing canonical object/relationship or universal composition contract.
3. Configure local schema, workflow, policy, authority, resource or reporting requirements.
4. Record evidence and unresolved assumptions.
5. Only propose constitutional change when the missing semantic cannot be expressed without contradiction or ambiguity in the universal model.

## Product rule

Emirati and other products MUST consume the universal substrate and composition services. They must not create competing object graphs, authority systems, or foundational kernels merely to satisfy local requirements.

## Operational proof

A complete composition should be able to move from:

`need → situation → data/form → authority → plan/workflow → resources/capacity → execution → state/event → evidence → value → report → learning → continuity`

with exceptions, emergency escalation and human intervention preserved throughout.
