# OMNII Ecosystem Composition Index

**Status: CANONICAL — universal Lego/composition index**

This index defines reusable composition categories for Carbon Actual ecosystems. It is an index of capabilities, not a second ontology.

## Core composition families

### Actors and identity
Person, family, organization, institution, community, group, authority-holder, agent, visitor, participant.

### Places and territory
Territory, region, venue, route, site, facility, address, zone, boundary, jurisdiction.

### Assets and resources
Property, vehicle, animal, equipment, inventory, material, room, capacity, service capacity, financial resource.

### Relationships
Membership, ownership/custody, affiliation, representation, hosting, sponsorship, delegation, participation, trust, communication, governance, dependency.

### Time and activity
Calendar, schedule, event, situation, activity, occurrence, period, recurrence, deadline, availability window.

### Process and decision
Intent, action, workflow, task, approval, decision, case, escalation, exception, resolution.

### Rules and authority
Authority, policy, rule, permission, consent, jurisdiction, mandate, role, delegation, revocation.

### Information and proof
Knowledge, record, schema, form, submission, document, evidence, proof, report, audit, provenance.

### Commerce and value
Offer, listing, quote, price, cost, transaction, payment, obligation, commitment, contribution, value, economic position.

### Movement and logistics
Journey, route, transport, shipment, allocation, dispatch, reservation, accommodation, hosting, traffic state.

### Safety and continuity
Risk, readiness, incident, emergency, response, medical support, security support, recovery, continuity, after-action learning.

### Intelligence and learning
Observation, telemetry, signal, Pulse, analysis, prediction, simulation, recommendation, learning artifact, Becoming.

### Interfaces and integration
IO, API, message, notification, integration, adapter, queue, scheduler, worker, authorized agent.

## Composition rule

Any product or ecosystem may compose these categories in arbitrary combinations without creating a new constitutional primitive unless a genuine semantic gap is proven.

Emirati is expected to consume this index as a composition layer and specialize it through local authority, protocol, culture, calendar, language, rules and workflows.
