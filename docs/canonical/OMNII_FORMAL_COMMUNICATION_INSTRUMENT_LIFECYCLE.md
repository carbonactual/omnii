# OMNII Formal Communication & Instrument Lifecycle

**Status:** CANONICAL CAPABILITY SCOPE  
**Parent:** `docs/canonical/OMNII_COMMUNICATION_PRESENCE_FABRIC.md`  
**Companions:** `docs/canonical/OMNII_COMMUNICATION_INTELLIGENCE_TAXONOMY.md`, `docs/canonical/OMNII_COMMUNICATION_INTERACTION_OPERATIONS.md`  
**Intelligence:** ABBA orchestration  
**Scope:** Person-to-person, household, organization, institutional, governmental, diplomatic, legal, judicial, administrative, commercial, educational, medical, emergency, justice/custody, public and machine-mediated consequential communication.

## 1. Canonical principle

Communication can remain conversational, but it can also become a governed instrument, official act, agreement, notice, record, decision, handoff, publication, appeal, obligation or other consequential artifact.

The ecosystem therefore models the complete lifecycle without creating separate product-specific document, signature, meeting, legal, records or communication primitives.

```text
INTENT
→ DISCOVERY / CONTACT
→ IDENTITY / REPRESENTATION
→ AUTHORITY / ROLE
→ CONSENT / NOTICE
→ DRAFT / PROPOSAL
→ REVIEW / NEGOTIATION
→ AGREEMENT / DETERMINATION
→ SIGN / SEAL / ATTEST / WITNESS
→ EXECUTE
→ DELIVER / HANDOFF / FILE / REGISTER
→ PUBLISH / NOTIFY / GAZETTE WHERE APPLICABLE
→ EFFECTIVE STATE
→ PERFORM / MONITOR
→ AMEND / CORRECT / RENEW / SUSPEND / TERMINATE
→ DISPUTE / APPEAL / REVIEW
→ RESOLVE / FINALIZE
→ ARCHIVE / RETAIN / EXPIRE
→ CONTINUITY / PROVENANCE / FEEDBACK
```

Legal or official effect must never be inferred merely because an artifact exists in the system. Jurisdiction, authority, applicable rules and required formalities govern effect.

## 36. Non-goals

This capability does not:

- declare an artifact legally valid merely because it exists;
- create a universal notary or court authority;
- infer criminal guilt, legal liability or official status from communications alone;
- equate publication with legal effectiveness;
- let an AI agent manufacture human approval;
- replace jurisdiction-specific law;
- create duplicate identity, document, task, relationship or registry systems inside products;
- expose private records merely because a communication references them;
- turn every conversation into a permanent record.

## 37. Canonical boundary

The ecosystem owns the **continuum and capability**.

Products own only the exact presentation, workflow configuration and product-specific experience.

```text
PRODUCT
  ↓
COMMUNICATION / INTERACTION FABRIC
  ↓
FORMAL INSTRUMENT CAPABILITY
  ↓
IDENTITY + AUTHORITY + SEAL
  ↓
REGISTRIES / TRACEABILITY / VAULT
  ↓
ABBA INTELLIGENCE
  ↓
ECOSYSTEM CONTINUITY
```

Nothing consequential should become an isolated island inside a product when the ecosystem already has the applicable common capability.
