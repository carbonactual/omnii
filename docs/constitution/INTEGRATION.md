# INTEGRATION

Integration is the constitutional kernel governing interoperability among kernels, objects, products, agents, services, institutions, and external systems.

## Purpose
Allow distinct systems to participate in OMNII without collapsing their boundaries or redefining constitutional primitives.

## Canonical Concerns
- Interfaces
- Adapters
- Protocols
- Events
- Contracts
- Interoperability
- Boundary translation

## Invariant
Integration must preserve the identity, authority, provenance, and semantics of the systems being connected.
