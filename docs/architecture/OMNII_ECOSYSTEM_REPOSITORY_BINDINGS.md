# OMNII Ecosystem Repository Bindings

**Status:** Canonical estate binding view — 2026-09-14

Repository binding is a control-plane classification. It does not turn a repository into constitutional truth and does not require copying, merging, deleting or archiving repositories.

Provider rule:

`provider capability → adapter → canonical contract → policy/authority → runtime`

A provider outage, API shape, license, pricing model, internal ontology or implementation detail does not redefine OMNII semantics.

## BUNK boundary

BUNK remains a downstream property/housing composition. Its code currently resident inside `carbonactual/omnii` is not a constitutional dependency. Physical extraction into a separately bounded repository is a controlled migration task and is intentionally not performed by this registry update.

## Promotion rule

A repository binding is not a production claim. Production status requires runtime/deployment evidence under the Control Plane promotion ladder.

## Estate rule

`inventory → classify → bind → conform → compose → verify → promote`

Never:

`inventory → copy everything → merge everything → call it canonical`
