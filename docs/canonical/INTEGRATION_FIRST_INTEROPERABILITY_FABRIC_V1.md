# Integration-First Universal Interoperability Fabric v1

Integration is a first-class OMNII capability. OMNII owns universal contracts and invariants for connecting identities, names, capabilities, protocols, providers, agents, services, data sources, devices and external systems. External systems remain independently governed.

## Non-conflations

`#` is the HAPI↔AI identity bridge, not authority. SEAL is explicit human authority. Resolution does not grant trust. Verification does not grant authority. Capability identity does not equal provider identity. MCP/A2A/API/SDK/CLI/WEB/LOCAL are replaceable execution rails. `MINT != TOKENIZE`, `MINT -> TERMINAL`, `TOKENIZE -> INDEX`.

## Integration lifecycle

`DISCOVERED -> IMPORTED -> QUARANTINED -> TESTING -> ADMITTED -> ACTIVE`

with explicit `DEGRADED`, `REVOKED`, and `DEPRECATED` states. Revoked integrations cannot silently return to active.

## Identity and resolution

DID, ENS, HNS, DNS and URI/name systems coexist as complementary schemes. The required sequence is:

`DISCOVER -> RESOLVE -> VERIFY -> CORRELATE -> PROVE -> AUTHORIZE -> INTEGRATE`

A resolution result is never itself SEAL authority.

## Capability admission

External capabilities begin quarantined and move through evidence-backed license, security, SBOM, provenance, sandbox, capability, Pulse, policy and, when required, SEAL gates. Trust may degrade or revoke explicitly.

## Routing

Default preference: deterministic→CLI; structured tool/data→MCP; agent delegation→A2A; direct service→API; embedded performance→SDK; browser/external world→WEB; private/edge→LOCAL. Unsafe or unauthorized candidates are removed before ranking; `no-safe-route` is valid.

## Accountability

Integration outcomes feed existing Proof/Pulse/Value semantics. Meaningful feedback may be minted and routed to Terminal. Minting does not create Index membership; explicit curation/tokenization remains required.

## Replaceability

Providers are adapters, not constitutional dependencies. Open standards, self-hostable/open-source implementations and free/open core paths are preferred. Commercial hosted services remain optional adapters.
