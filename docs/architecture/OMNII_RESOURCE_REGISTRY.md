# OMNII RESOURCE REGISTRY

Runtime registry of resources that can be allocated, consumed, reserved, or governed by execution.

## Resource Record
Identity, resource type, owner/steward, location or endpoint where applicable, capacity, availability, constraints, lifecycle, provenance, and authority.

## Resolution
Resources are resolved against requested capability, constraints, availability, compatibility, and authority.

## Invariants
Discovery does not reserve a resource. Allocation requires authority. Consumption and release are observable and attributable. Physical and human resources remain explicitly represented rather than being reduced to abstract compute.
