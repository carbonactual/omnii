# OBJECT REGISTRY DEFINITIONS

The Object Registry Definitions establish the canonical structure for constitutional objects within OMNII.

## Purpose
Give every constitutional object a stable identity, semantic type, lifecycle, authority boundary, provenance, and relationship surface.

## Required Object Properties
- Object ID
- Canonical name
- Type
- Status
- Owner or authority
- Provenance
- Version
- Lifecycle
- Relationships
- Dependencies
- Capabilities
- Constraints

## Invariant
A product may instantiate or compose canonical objects but must not redefine their constitutional meaning locally.
