# KERNEL RELATIONSHIP MAP

## Purpose
Canonical map of semantic relationships among OMNII constitutional kernels.

## Core Map
| Kernel | Primary relationships |
|---|---|
| BEING | grounds Identity and existence |
| IDENTITY | represents Being and anchors attribution |
| KNOWLEDGE | describes, remembers, evidences, contextualizes |
| MOTION | expresses change and transition |
| VALUE | measures contribution, exchange, stewardship |
| TRUST | governs confidence, consent, verification |
| RELATIONSHIP | connects constitutional objects |
| INTENT | gives purpose and direction |
| EXECUTION | turns intent into action/state transition |
| CAPABILITY | defines ability and permitted use |
| RESOURCE | supplies consumable/controllable capacity |
| COMPOSITION | assembles objects and capabilities into systems |
| CONTINUITY | preserves identity, state, history, and provenance through time |
| INTEGRATION | crosses system and boundary interfaces |

## Cross-Cutting Layers
- GOVERNANCE constrains authority, rights, delegation, and constitutional change.
- ORCHESTRATION/ABBA coordinates authorized activity across kernels.
- ECONOMIC CONSTITUTION governs economic participation and value mechanisms.
- AGENT CONSTITUTION governs intelligent agents as constitutional participants.

## Rule
Relationship entries must identify semantic direction, authority implications, lifecycle, and provenance. A product-specific relationship must not redefine a constitutional relationship.
