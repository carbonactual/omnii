# OMNII EXECUTION RUNTIME

Universal execution turns intent into authorized, observable effects.

## Runtime Path
`Intent → Resolve Capability → Resolve Resource → Authorize → Execute → Emit Event → Apply State → Observe`

Execution is attributable to an identity/agent, bounded by authority and policy, connected to explicit capability and resource records, and represented by events.

## Failure
Execution failures become explicit state/events and may invoke retry, compensation, quarantine, or recovery policies.
