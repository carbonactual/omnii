# OMNII UNIVERSAL COMPOSITION ENGINE

## Purpose
Define the runtime mechanism for assembling canonical objects, kernels, capabilities, resources, agents, humans, services, workflows, and integrations into products and systems.

## Inputs
Composition intent, canonical objects, compatible capabilities, resources, relationships, contracts, constraints, and governance rules.

## Process
Discover → Validate → Resolve dependencies → Authorize → Assemble → Configure → Test → Activate → Observe → Evolve/Retire.

## Outputs
Composition graph, executable configuration, interfaces, dependency records, capability map, resource plan, and lifecycle state.

## Invariants
The engine composes canonical primitives; it does not redefine them. Every component remains attributable and replaceable only under compatibility and authority rules.

## ABBA
ABBA may operate as the intelligent orchestration controller for composition while governance retains authority over prohibited or reserved compositions.
