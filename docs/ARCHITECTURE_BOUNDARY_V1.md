# OMNII Boundary and BUNK Extraction v1

OMNII is the constitutional/universal ecosystem architecture and kernel. It is not the BUNK product and it is not the OMNI product.

OMNII retains universal ontology, relationship/dependency semantics, identity and authority contracts, capability/integration contracts, Value/Pulse/Proof/Actual semantics, IO/settlement contracts, Terminal/curation/tokenization/Index lifecycle contracts, Ash/Phoenix/no-waste contracts, provider-neutral integration and experience semantics.

BUNK-specific property ontology, listings, tenancy, inspection, maintenance, marketplace and product UX remain BUNK-owned. The required dependency direction is:

`BUNK -> OMNII contracts`

`BUNK -> ABBA capabilities`

`BUNK -> HAPI/HAPI World capabilities`

`BUNK -> IO/Value/Proof/Pulse/Actual/SEAL`

No reverse dependency from OMNII constitutional code into BUNK product internals is permitted.

## Extraction boundary

The repository contains a source inventory for eventual standalone BUNK extraction. No source deletion occurs until the standalone repository exists, contents are verified, consumers are mapped, and rollback is possible. Repository creation remains an external GitHub administrative boundary.
